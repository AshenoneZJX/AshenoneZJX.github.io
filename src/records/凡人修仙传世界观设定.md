# 凡人修仙传世界观设定

## 一、宗派体系框架
宗派体系围绕人界、灵界、仙界的地域差异与资源分布形成，核心是正魔两大阵营对立，辅以中立势力、特殊族群与仙界统治集团，共同构成复杂的修仙势力格局。

|界面|核心势力|代表宗派/组织|核心特点|
| ---- | ---- | ---- | ---- |
|人界|越国七大派|掩月宗、黄枫谷、灵兽山、清虚门等|正道支柱，掩月宗实力最强，黄枫谷中立，功法融合正邪传承|
|人界|魔道六宗|鬼灵门、御灵宗、魔焰门等|与正道长期对抗，以诡异功法、阴毒手段著称|
|人界|天南地区|落云宗、古剑门、百巧院|溪国三派，分别擅长炼丹、御剑、炼器，为天道盟核心门派|
|人界|乱星海|星宫、逆星盟|星宫为乱星海霸主，逆星盟为反抗势力，长期争斗|
|灵界|真灵世家|陇家、谷家、叶家|传承上古血脉，拥有合体级强者，陇家为灵界第一世家|
|灵界|天渊城|无特定宗派|修炼速度超外界一倍，资源丰富，修士聚居地|
|灵界|天云十三族|13小族组成|大乘数量8-12名，与角蚩族多次冲突|
|仙界|天庭|无特定宗派|仙界正统统治者，掌控三千大道秩序，以时间道祖古或今为首|
|仙界|轮回殿|无特定宗派|与天庭对立，反抗古或今统治，轮回殿主为核心领袖|

## 二、修仙等级框架分析
修仙等级分为三大阶段，共13个主要境界，每个境界都有明确的实力提升、寿元增长与进阶要求，除炼气期外，多数境界细分为初、中、后期。

### （一）人界篇（下境界）
1. **炼气期**：共13层，无初、中、后期划分，前九层打通奇经八脉，后四层凝聚丹田气旋，寿元约100-120岁，可施展基础法术，使用**法器**（低阶修士的标配），是修仙起点。
2. **筑基期**：灵气化液，可御剑飞行、辟谷，寿元约300岁，能使用**法器**，布置初级阵法，是**仙凡之别的分水岭**。
3. **结丹期**：丹田液态真元凝聚成金丹，寿元约500岁，神识与法力大幅提升，可施展更强大法术，使用**法宝**，是人界高端战力基础。
4. **元婴期**：金丹碎裂，元婴诞生，寿元可达千岁，神识范围覆盖百余里，能全方位监控周边环境，具备显著信息优势。
5. **化神期**：可引动天地灵气，与五行之力相合，肉身不灭，具备飞升灵界之资，是人界修仙顶点。

### （二）灵界篇（中境界）
1. **炼虚期**：元婴发展为少年形态，可化为虚影，能炼化天地元气自用，细分为初、中、后期，寿元大幅增长。
2. **合体期**：元婴与肉身融合，虚影凝实显化真身，进一步掌握法则之力，细分为初、中、后期。
3. **大乘期**：无明确阶段划分，仅分强弱，需渡五行之劫、真雷劫与心魔劫，元婴固化升华，肉身重铸，可自如运用法则之力，大乘圆满后进入渡劫期，准备飞升仙界。

### （三）仙界篇（上境界）
1. **真仙境**：飞升仙界后的基础境界，肉身不朽、元神不灭，初步掌握法则，寿命近乎无限。
2. **金仙境**：真仙打通36仙窍后进阶，可凝聚法则之丝，施展基础灵域，需渡魂衰、煞衰。
3. **太乙境**：金仙打通108个仙窍后进阶，玉体初成，法则领悟更深，实力远超金仙。
4. **大罗境**：法则圆满，可融合多种法则，施展强大灵域，寿元近乎永恒，是仙界高端战力。
5. **道祖境**：执掌大道本源，不再细分阶段，是修仙终极境界，如时间道祖古或今，掌控时间法则，势力遍布各大仙域。

## 三、进阶关键要点
1. **境界递进**：从炼气到道祖，是生命本质的不断跃迁，每突破一个大境界，寿元与实力都会大幅提升，如元婴期寿元达千岁，真仙境寿命近乎无限。
2. **渡劫考验**：化神期渡飞升之劫入灵界，大乘期渡飞升之劫入仙界，仙界各境界也需渡不同劫难，如金仙渡魂衰、煞衰。
3. **法则掌握**：灵界篇开始接触法则之力，仙界篇以领悟与掌控法则为核心，道祖境执掌大道本源，是法则修炼的终极目标。
