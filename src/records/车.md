# 车

## 选车原则

1. 选销量高的热门车型

2. 不要选质量差的豪华品牌
3. 尽量买空间大的
4. 买便宜的
5. 选家里附近有4S店的品牌
6. 不主动贷款，不要超前消费

> 1个月收入买手机、数码电器；
>
> 1年收入买车；
>
> 10年收入买房。

---

### **一、2025年汽车市场现状**
1. **价格战持续**  

   - 新能源**更新快**，新车易遭“背刺”（如秦PLUS直降2万至7万出头）。  
   - 燃油车受冲击大幅降价，部分车型五折甩卖。  

   **建议**：非刚需可观望，刚需重点关注年底（12月）或淡季（暑假）购车。  

2. **4S店风险**  
   - 2024年超4400家门店退网，需关注门店经营状况（社交媒体查投诉、天眼查查经营）。  
   - 警惕附加费：上牌费＞500元、PDI检测费、金融服务费均为不合理收费。

### **三、理性购车预算**
- ==**公式**：**车辆总价 ≤ 年结余收入 × 1.5倍**（贷款月供+房贷≤月收入50%）。==  
- **参考建议**：  
  - 月薪5k：选7万内（轩逸、帝豪）；  
  - 月薪1万：选12万左右（秦L、深蓝S07）；  
  - 月薪1.5万：选18-25万（Model 3、汉兰达）。  
- **避坑**：  
  - 拒绝“零首付/长贷”套路，优先全款。==贷款有优惠例外==
  - 车是消费品而非资产，不能增值，持续消耗现金流（油费、保险、贬值），理性购买。  

### **四、避坑砍价全攻略**
#### **1. 费用清单（5项必须）**
| **费用** | **说明**                 | **避坑要点**                            |
| -------- | ------------------------ | --------------------------------------- |
| 车价     | 合同裸车价（非指导价）   | 拒绝低开发票（影响保险赔付/二手车估值） |
| 购置税   | 燃油车必交（≈车价÷11.3） | 新能源免购置税                          |
| 上牌费   | 自办仅125-225元          | 4S代办＞500元可拒付                     |
| 保险费   | 交强险（950元）+商业险   | 拒绝“全险”，必买车损险+三者险（300万）  |
| 车船税   | 燃油车按排量征收         | 新能源免征                              |

#### **2. 砍价技巧**
- **查底价**：用汽车报价APP查本地成交价（需付出电话骚扰代价）。  
- **时机**：月末/季末/年末冲销量时，或老款换代前。  
- **话术**：  
  - 携带竞品4S店报价单对比；  
  - 温和压价：“这价格超预算了，能否申请领导优惠？”；  
  - 赠品折现优先（保养券、油卡＞脚垫、贴膜）。  

### **五、提车验车流程**
**1. 文件核对**

必取6项：**发票（四联）**、合格证、车辆一致性证书、三包凭证、交强险保单、环保标志。  
> 重点查合格证！部分4S店抵押给银行，无证无法上牌。

**2. 验车清单**

| **项目**     | **检查要点**                                                 |
| ------------ | ------------------------------------------------------------ |
| **外观**     | 漆面划痕/凹陷（用手电筒斜照）、玻璃生产日期（早于整车出厂日期） |
| **轮胎**     | 胎毛是否存在、生产日期（4位数字：周数+年份）、无翻新痕迹     |
| **内饰**     | 座椅磨损、按键功能（车窗/空调/灯光）、中控屏故障             |
| **发动机**   | 启动无异响、油液（机油/刹车油）在刻度内、舱内无漏液          |
| **里程**     | ≤100公里（运输正常范围）                                     |
| **随车工具** | 三角警示牌、反光背心、备胎（如有）                           |

**3. 上牌流程**

- **材料**：身份证+合格证+购车发票+交强险保单+居住证（异地）。  

- **步骤**：缴购置税→车管所验车（需警示牌/背心拍照）→选号（12123APP可预选）→制牌。 

### **六、总结**
1. **非刚需观望**：价格战持续，新能源技术迭代快，晚买更划算。  
2. **选畅销车型**：高销量=高保值率+低维修成本（如特斯拉、比亚迪）。  
3. **深度试驾**：花几百元租2天模拟真实路况，避免4S店套路化试驾路线。  
4. **警惕“服务陷阱”**：预付费保养套餐可能因门店倒闭失效。

## 汽车基本知识

### 动力：最核心的配置

#### 燃油

> - 补能方便、没有里程焦虑
> - 使用成本高
> - 技术成熟可靠
> - 保值率高

##### **一、发动机**

>  为汽车提供动力输出

**分类：**

1. **自然吸气发动机**：日常所见1.5L、2.0L即自然吸气发动机。动力输出线性、技术成熟可靠，油耗相对较低，动力相对弱
2. **涡轮增压发动机：**1.5T、2.0T即涡轮增压发动机。动力更强，油耗相对高

**发动机参数：**

1. **最大功率：**用`kw`或`马力（Ps）`表示，决定了汽车的最大速度和加速能力

2. **最大扭矩：**发动机输处力矩，决定了汽车的瞬时加速能力和爬坡能力，单位`N·m`

##### **二、变速器**

> 改变发动机输出的转速和扭矩，以适应不同的驾驶条件

分为：手动变速器（C1)、自动变速器（C2)

##### **三、传动系统**

> 将发动机动力传递到车轮上，传动系统直接影响汽车的动力输出和操控性能。由离合器、传动轴、差速器等部件组成。

传动系统类型：

1. 前置前驱：成本低、传动效率高，但可能出现转向不足
2. 前置后驱：前后配重均衡，操控性稳定性好，但结构复杂成本高
3. 后置后驱：能提高加速性能和操控性，新能源车（特斯拉，小米）使用多
4. 四轮驱动：分全时四驱、分时四驱、适时四驱。四驱性能强成本高

对大部分普通人两驱足够。**百公里加速时间**（时速从0加速到100km/h所需时间）也是动力水平的评价参数之一。

#### 纯电

> - 电力使用成本低，一公里几毛钱
> - 电机瞬时扭矩大，动力充足
> - 车内环境安静
> - 不方便充电
> - 不适合走烂路，容易磕到底盘电池包

**动力系统组成：**

1. **电池：**电能单位`kWh（度）`。分**三元锂电池**（能量密度更高，低温性能相对较好，安全性更低，成本高）和**磷酸铁锂电池**。三元锂电池多用于高端车。

2. **电动机：**扭矩大、响应速度快、零排放。分为永磁同步电机（目前纯电汽车应用最广泛）、异步电机（感应电机）、直流电机。

3. **电控系统：**控制电动机运行，实现对汽车动力的精确控制。包括电池管理系统、电机控制器、整车控制器。

**高压平台：**搭载高压平台的汽车工作电压在`400V`以上，能提供**高动力输出**和**快速充电**。

#### 混动

1. **油电混动：**只能加油，不能充电，挂蓝牌。电动机仅在汽车起步、加速等需要较大动力时辅助内燃机工作，高速稳定行驶主要依靠内燃机。电池较小，电量通过车辆行驶时的能量回收及内燃机运转时的充电来维持，不能纯电行驶。**代表车型：丰田卡罗拉双擎、本田型格HEV。**

​	**适合需求：**主要在城市行驶；行驶里程短；对燃油经济性要求高；不希望有续航焦虑；

2. **插电式混动：**可油可电，挂绿牌。两套动力系统，既有燃油车的发动机和油箱，又有纯电车的电动机和电池。插混汽车在电池电量充足时依靠动力电池作为动力，能提供一定的纯电续航里程。当电量不足时发动机启动，使用传统内燃机作为动力行驶。**代表车型：比亚迪秦PLUS DM-i、宋PLUS DM-i。**

​	**适合需求：**日常通勤距离长；有方便的充电条件；想有纯电乘驾体验；对动力表现有一定需求

3. **增程式混动：**可油可电，挂绿牌。发动机不直接参与动力输出，只作为发电机产生电能为电池充电，电动机负责驱动车轮。增程技术相对落后（插混技术厂商可做增程车，增程技术厂商很难做插混），可能油耗较高。**代表车型：理想L7、长安深蓝SLO3、问界M7。**

​	**适合需求：**更追求纯电驾驶体验；对续航里程有较高要求；大部分用车在城区。
