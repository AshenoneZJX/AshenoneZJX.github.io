

# 比亚迪集团品牌及车型架构图

## 集团概览

比亚迪集团已形成**"金字塔式"多品牌矩阵**[^3^]，覆盖从家用到豪华、从大众到个性化的全场景用车需求：

```plain
            ┌─────────────┐
            │   仰望      │  ← 百万级超豪华 (塔尖)
            │  (80-150万) │
            └──────┬──────┘
                   │
      ┌────────────┼────────────┐
      │            │            │
 ┌────┴────┐  ┌────┴────┐  ┌────┴────┐
 │  腾势   │  │ 方程豹  │  │  领汇   │
 │(35-70万)│  │(28-70万)│  │(B端出行)│
 └────┬────┘  └────┬────┘  └────┬────┘
      │            │            │
      └────────────┴────────────┘
                   │
            ┌──────┴──────┐
            │   比亚迪    │  ← 大众市场 (塔基)
            │ (6-35万)    │
            │ 王朝+海洋   │
            └─────────────┘
```

## 一、比亚迪主品牌 (BYD)

> **定位**：大众消费市场主力品牌，销量基本盘  
> **价格区间**：6-35万元  
> **渠道**：王朝网 + 海洋网双网并行

## 架构总结

| 层级     | 品牌              | 定位       | 价格带   | 核心使命             |
| -------- | ----------------- | ---------- | -------- | -------------------- |
| **塔尖** | 仰望              | 超高端豪华 | 80-150万 | 技术标杆、品牌向上   |
| **塔身** | 腾势              | 主流豪华   | 35-70万  | 高端商务市场         |
| **塔身** | 方程豹            | 个性化豪华 | 28-70万  | 越野/个性化市场      |
| **塔身** | 领汇              | B端营运    | -        | 对公出行生态         |
| **塔基** | 比亚迪(王朝+海洋) | 大众消费   | 6-35万   | 销量基本盘、技术平权 |

**战略逻辑**：分层定位、全域覆盖、技术协同[^3^]
