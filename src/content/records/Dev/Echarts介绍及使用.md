# ECharts 介绍及使用指南（新手向）

如果你是一名前端新手，或者刚接触数据可视化，想要把枯燥的表格数据变成网页上酷炫、可交互的图表，那么 **Apache ECharts** 绝对是你的不二之选！

这篇文章将用最通俗易懂的语言，带你了解什么是 ECharts，它有什么神奇的功能，以及如何用 5 分钟画出你的第一张图表。

---

## 一、 什么是 ECharts？

简单来说，**ECharts 是一个用 JavaScript 写的开源“画图工具”**。
不管你是想画折线图、柱状图、饼图，还是复杂的地图、关系图，它都能帮你轻松搞定。它可以在电脑和手机浏览器上流畅运行，并且提供了极其丰富的交互功能（比如鼠标悬停显示数据、滑动滚轮缩放图表等）。

---

## 二、 为什么大家都爱用 ECharts？（核心亮点）

根据 [ECharts 官方特性介绍](https://echarts.apache.org/zh/feature.html)，它有以下几个让开发者爱不释手的绝招：

1. **图表类型极其丰富，还能“混搭”**
   - 常规的：折线图、柱状图、饼图、散点图。
   - 高级的：K线图（炒股用的）、地图、热力图、漏斗图、仪表盘等。
   - 你甚至可以把柱状图和折线图画在同一张表里，想怎么搭就怎么搭！

2. **千万级数据“丝滑”展现**
   - 如果你的数据量极大（比如几万甚至几百万条），普通的图表库早就卡死崩溃了。但 ECharts 内部有增量渲染等“黑科技”，哪怕数据再多，也能流畅地进行缩放和平移。

3. **完美适配手机端**
   - 在手机屏幕上，你可以直接用手指捏合来缩放图表，滑动来平移。它的安装包可以做得很小，对手机内存也非常友好。

4. **多种画笔（渲染方案）随便挑**
   - 它支持 **Canvas** 和 **SVG** 两种渲染方式。数据量大、特效多就用 Canvas；想要在手机上省内存、图片无限放大不失真就用 SVG。

5. **极其丰富的交互**
   - “总览为先，缩放过滤按需查看细节”。它自带了图例切换、数据区域缩放、数据提示框（Tooltip）等开箱即用的交互组件。

## 三、 新手 5 分钟快速起步

不要被复杂的配置吓到，画一个最基础的 ECharts 图表只需要 **三个步骤**！

### 第一步：引入 ECharts 库
你可以直接在 HTML 文件中通过 CDN 引入 ECharts 的代码文件（就像引入普通的 JS 文件一样）。

### 第二步：准备一个“画板”（容器）
在网页里放一个 `<div>` 标签，并且**一定要给它设置宽度和高度**，这就是 ECharts 画图的地方。

### 第三步：写几行配置代码
告诉 ECharts 你要画什么图，数据是什么。

**👉 完整体验代码（你可以直接复制保存为 `.html` 文件在浏览器中打开）：**

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>我的第一个 ECharts 图表</title>
    <!-- 1. 引入 ECharts -->
    <script src="https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js"></script>
</head>
<body>
    <!-- 2. 准备一个有宽高的 DOM 容器（画板） -->
    <div id="main" style="width: 600px; height: 400px; background-color: #f4f4f4;"></div>

    <script>
        // 3. 初始化并画图
        // 找到我们刚才准备好的画板
        var chartDom = document.getElementById('main');
        // 让 ECharts 在这个画板上初始化
        var myChart = echarts.init(chartDom);

        // 编写图表的“说明书”（配置项）
        var option = {
            title: {
                text: '程序员最爱喝的饮料销量' // 图表标题
            },
            tooltip: {}, // 鼠标放上去会有提示框
            xAxis: {
                data: ['可乐', '雪碧', '咖啡', '奶茶', '苏打水'] // X轴的标签
            },
            yAxis: {}, // Y轴会自动根据数据生成刻度
            series: [
                {
                    name: '销量',
                    type: 'bar', // type 决定了画什么图：'bar' 是柱状图，'line' 是折线图，'pie' 是饼图
                    data: [120, 80, 200, 150, 90] // 具体的销量数据
                }
            ]
        };

        // 把这份说明书交给 ECharts，它就会帮你把图画出来！
        myChart.setOption(option);
    </script>
</body>
</html>
```

## 四、 秒懂 ECharts 的核心概念：`option`（配置项）

在上面的例子中，你会发现大部分时间我们都在写 `option` 这个大对象。**在 ECharts 中，几乎所有的图表长什么样，都由 `option` 说了算。**

简单拆解一下 `option` 里最常用的几个“零件”：

- **`title`**：图表顶部的标题。
- **`tooltip`**：提示框。不配置的话鼠标放上去没反应，加上它，鼠标悬停在柱子上就会显示具体数值。
- **`legend`**：图例。比如图里有红色和蓝色的线，图例会告诉你红色代表“2023年”，蓝色代表“2024年”。点击图例还能控制某条线的显示和隐藏。
- **`xAxis` 和 `yAxis`**：直角坐标系的 X 轴（横轴）和 Y 轴（纵轴）。
- **`series`（系列）**：**最重要的一环！** 它是一个数组，里面存放着你要展示的数据。通过里面的 `type` 属性，你可以随心所欲地切换图表类型（比如把 `'bar'` 改成 `'line'`，柱状图瞬间变成折线图）。

## 五、 总结

ECharts 就像是一个功能强大的“乐高积木箱”。刚开始，你只需要学会拼最简单的“小汽车”（如上文的柱状图）。等你熟练之后，你可以去 [ECharts 官方示例集](https://echarts.apache.org/examples/zh/index.html) 里看看别人拼的“航空母舰”，遇到喜欢的，直接把他们的 `option` 代码抄过来，换成你自己的数据，就能变成你的图表！
