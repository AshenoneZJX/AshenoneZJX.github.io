# Markdown使用教程

## 语法

### 1 标题
Markdown 标题有两种格式：
1. **使用 `=` 和 `-` 标记一级和二级标题**
   ```markdown
   一级标题
   =========
   二级标题
   ---------
   ```
2. **使用 `#` 号标记**
   使用 `#` 号可表示 1-6 级标题，一级标题对应一个 `#` 号，二级标题对应两个 `#` 号，以此类推。
   ```markdown
   # 一级标题
   ## 二级标题
   ### 三级标题
   #### 四级标题
   ##### 五级标题
   ###### 六级标题
   ```

### 2 段落格式
- **段落**：Markdown 段落没有特殊的格式，直接编写文字就好，段落的换行是使用两个以上空格加上回车或者在段落后面使用一个空行来表示重新开始一个段落。
- **字体**：
  ```markdown
  *斜体文本*
  _斜体文本_
  **粗体文本**
  __粗体文本__
  ***粗斜体文本***
  ___粗斜体文本___
  ```
- **分隔线**：你可以在一行中用三个以上的星号、减号、底线来建立一个分隔线，行内不能有其他东西。
  ```markdown
  ***
  * * *
  *****
  - - -
  -----------
  ```
- **删除线**：删除线只需要在文字的两端加上两个波浪线 `~~` 即可。
  ```markdown
  ~~删除内容~~
  ```
- **下划线**：下划线可以通过 HTML 的 `<u>` 标签来实现。
  ```markdown
  <u>下划线文本</u>
  ```

### 3 图片
Markdown 的图片语法如下：
```markdown
![替代文字](图片位置)
```
开头一个感叹号 `!`，接着一个方括号，里面放上图片的替代文字，接着一个普通括号，里面放上图片的网址。

如果你想指定图片的大小则要使用 `<img>` 标签指定宽（width）和高（height）。
```html
<img src="图片路径" width="50%">
```

### 4 代码
代码在用 Markdown 中用 ``` 包裹一段代码，并指定一种语言（也可以不指定）：
```markdown
\```css
body{
  background:url(img/bg.jpg) no-repeat center center;
  background-size:cover;
  background-attachment:fixed;
  background-color:#CCCCCC;
}
\```
```

### 5 列表
Markdown 支持有序列表和无序列表。
- **无序列表**：使用星号 `*`、加号 `+` 或是减号 `-` 作为列表标记。
  ```markdown
  * 第一项
  * 第二项
  ```
- **有序列表**：使用数字并加上 `.` 号来表示。
  ```markdown
  1. 第一项
  2. 第二项
  ```

## 本地图片资源路径问题
本地图片在 Markdown 中无法正常显示的原因在于： 构建工具（Webpack/Vue CLI）处理静态资源的机制。

你的项目是通过 raw-loader （或者类似的文本加载器）来读取 Markdown 文件的原始内容，然后交给 MarkdownIt 解析。在这个过程中，Markdown 里的图片路径 `../../assets/images/carBasicArticle/L113.jpg` 会作为纯文本保留在生成的 HTML 中。
但是，Vue 项目只有在 .vue 组件里通过 import 或 `<img src="~@/assets/...">` 引入的图片，才会被 Webpack 处理并打包到最终的输出目录。纯文本中的相对路径在浏览器运行时无法找到对应的本地 src/assets 目录，因此就出现了 404（图片加载失败）。

### 解决办法
将需要动态引用（通过 Markdown 文本引用）的静态资源，放在项目的 public 目录下。 public 目录中的文件在构建时会被原封不动地复制到根目录，可以直接通过绝对路径 / 访问。
1. 创建了对应的公开目录并将图片移入：将 `src/assets/images/carBasicArticle/L113.jpg` 移动到了 `public/images/carBasicArticle/L113.jpg` 。
2. 修改了 body-size.md 中的图片引用路径。
未来如果在 Markdown 中引用新的本地图片，也请按照这种方式，将图片放在 public 目录下，并使用根路径 / 引用。
