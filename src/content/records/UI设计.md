# UI设计基础知识

## 单位
px是像素单位，em是相对单位，pt是绝对单位。它们各自的好处是：
1. px可以在计算机屏幕上，能达到预期的效果，在打印机和其他高分辨率设备上，它又能取得所希望的效果。
2. em的优点很多，比如在一个页面上，你给定了一个父元素的字体大小，这样就可以通过调整一个元素来成比例的改变所有元素大小。它可以自由缩放，比如用来制作可伸缩的样式表。
3. pt是一种固定长度的度量单位，是能够使用测量设备测得的长度。绝对单位作用有限，因为它们不能够缩放，通常只用在已经知道是用在哪种输出媒体的情况下才使用。但大多数情况下最好使用相对单位。一般都是用px和em这两种配搭比较好。

## 颜色

在 UI 设计中，色彩模型是表达和选择颜色的重要基础。虽然开发中常用基于加色法的 RGB 模型，但为了更符合人类感知和直观地选择颜色，设计师通常更偏好使用 **HSL** 或 **HSV**（也称 HSB）色彩空间。这两种模型都是将 RGB 色彩模型中的点表示在圆柱（或圆锥）坐标系中的方法。

### 基本属性
- **色相 (Hue, H)**：色彩的基本属性，对应平常所说的颜色名称（如红色、黄色等）。在模型中表示为绕中心轴的角度（0°-360°）。
- **饱和度 (Saturation, S)**：色彩的纯度。取值范围通常为 0-100%，值越高色彩越纯，越低则越接近灰色。到中心轴的距离对应饱和度。
- **亮度/明度 (Lightness/Value/Brightness, L/V/B)**：颜色的明暗程度。取值范围为 0-100%。

### HSL 与 HSV 的区别
这两种表示在目的上类似，都是用直观的“这是什么颜色？深浅如何？明暗如何？”来描述颜色，但在数学和概念上有明显区别：
1. **概念模型**：
   - **HSV (色相、饱和度、明度)**：可以被认为是一个倒圆锥体，黑点在下顶点，白色在上底面圆心。
   - **HSL (色相、饱和度、亮度)**：可以被认为是一个双圆锥体，白色在上顶点，黑色在下顶点，最大横切面的圆心是半程灰色（50%亮度）。
2. **“饱和度”的定义**：
   尽管两者中“色相”的定义相同，但它们对“饱和度”的计算方式和视觉表现是不同的。
3. **明度与亮度的表现**：
   - 在 HSV 中，明度 (Value) 为 100% 且饱和度为 100% 时是最纯正的颜色。
   - 在 HSL 中，亮度 (Lightness) 为 100% 时一定是纯白色，只有亮度为 50% 且饱和度为 100% 时才是最纯正的颜色。

### 应用场景
由于 HSL/HSV 以人类更熟悉的方式封装了关于颜色的信息，具有较强的感知度，它们在计算机图形界面（如颜色选择器、色轮）中被广泛应用，允许用户通过首先选择色相（圆环），然后再调整饱和度和明度（三角形或矩形区域）来快速选取所需的颜色。

## CSS 盒模型

在 Web 开发中，CSS 盒模型是指如何在浏览器引擎中对 HTML 元素进行建模，以及如何从 CSS 属性导出 HTML 元素的尺寸。所有 HTML 元素都可以被视为“框”（Box），其中包括 div 标签、p 标签或 a 标签等。
![CSS 盒模型](https://upload.wikimedia.org/wikipedia/commons/7/7a/Boxmodell-detail.png)

每个盒子都有五个可修改的尺寸属性：
1. **width / height**：指盒子实际内容的尺寸（如文本、图像等）。
2. **padding（内边距）**：指实际内容与盒子边框之间的空间。
3. **border（边框）**：围绕盒子的线条（如果存在的话，可以是实线、虚线等）。
4. **margin（外边距）**：边框外部的透明空间，用于控制盒子与其他元素之间的距离。

### 两种主要的盒模型

在 CSS 中，存在两种主要计算盒子总尺寸的盒模型，通过 `box-sizing` 属性进行控制：

1. **标准盒模型 (W3C Box Model / `content-box`)**：
   - 默认行为。
   - 当为元素显式设置宽度 (width) 或高度 (height) 时，它**仅确定可见内容的尺寸**。
   - **总宽度** = `left-margin` + `left-border` + `left-padding` + `width` + `right-padding` + `right-border` + `right-margin`。
   - **总高度** = `top-margin` + `top-border` + `top-padding` + `height` + `bottom-padding` + `bottom-border` + `bottom-margin`。
   - 缺点：增加 padding 或 border 会撑大元素的实际占用空间。

2. **IE 盒模型 (`border-box`)**：
   - 早期 Internet Explorer 的默认实现，后来在 CSS3 中被标准化为 `box-sizing: border-box`。
   - 元素的 `width` 和 `height` 属性包含了**内容 (content) + 内边距 (padding) + 边框 (border)**。
   - 增加 padding 或 border 不会改变元素的总尺寸，而是向内挤压实际内容区域。
   - 优点：更符合直觉，在现代前端开发中，通常推荐将所有元素重置为 `border-box` 以简化布局计算。
