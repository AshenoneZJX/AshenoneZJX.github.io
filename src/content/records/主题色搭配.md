# 主题色搭配（项目现状版）

本项目整体为「暗色 Steam 风格」：以深蓝灰中性色做大面积背景与层级面板，用高饱和浅蓝作为主强调色，辅以低透明度叠加来表达 hover / 选中 / 发光与分隔。

## 使用规范（推荐写法）

| 目标 | 推荐 | 不推荐 |
| --- | --- | --- |
| 交互背景（hover/选中） | 用主色低透明度叠加：`rgba(102,192,244,0.12~0.22)` / `#66c0f41f~#66c0f438` | 直接用纯主色大面积铺底（过亮、刺眼） |
| 强调边线/装饰 | 主色纯色或更高透明度：`#66c0f4` / `rgba(102,192,244,0.5)` | 任意新增高饱和颜色做描边（破坏统一） |
| 面板层级 | 从 L0~L4 选择一档背景，边线用 `#38424e` 或 `#2a475e` | 背景色随意挑选、导致层级对比混乱 |
| 弱分割与高光 | 用 `rgba(255,255,255,0.05~0.12)` 做微弱描边 | 用纯白描边（对比过强） |
