# 主题色搭配（Steam Dark 统一版）

本文档与 `/src/data/steam-theme.json` 保持一一对应，作为当前项目的统一色板基线。

## 关键 6 色

| 角色 | Token | 值 | 场景 |
| --- | --- | --- | --- |
| 主强调色 | `core.primary` | `#66c0f4` | 链接、激活态、强调边线 |
| 主背景 | `core.backgroundBase` | `#1b2838` | 页面主体背景 |
| 深背景 | `core.backgroundDeep` | `#171a21` | 页脚、深层容器 |

| 基础边框色 | `core.borderDefault` | `#38424e` | 输入框、分隔线、表格边框 |
| 强结构线 | `border.strong` | `#2a475e` | 区块分割、重点边线 |

## 使用规范

| 目标 | 推荐 |
| --- | --- |
| 交互背景（hover/选中） | 使用 `primaryAlpha` 的 `0.12 ~ 0.22` |
| 强调边线 | 使用 `core.primary` 或 `primaryAlpha.0.50` |
| 面板层级 | 优先从 `backgroundLevels` 与 `neutral` 中选用，不新增临时背景色 |
| 弱分割 | 使用 `whiteOverlayAlpha` 的 `0.05 ~ 0.12` |
