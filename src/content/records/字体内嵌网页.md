# 字体内嵌网页
## 可变字体与静态字体
**可变字体不完全等同于静态字体的作用，但在功能覆盖上可以替代同家族的多个静态字体**。两者的核心关联和区别可以拆解为以下两点：
1.  **功能覆盖层面：可变字体可包含同家族静态字体的所有样式**
    一个完整的可变字体，会把同家族静态字体的所有预设样式（如常规 400、粗体 700、细体 100）整合到单个文件中，并且允许你直接调用这些固定字重。
    比如你安装了思源黑体可变版，就可以在软件（如 PS、VS Code）里选择 400、700 等固定字重，效果和单独安装这些静态字体完全一致。
2.  **实际使用层面：存在两个关键差异**
    - **兼容性差异**：部分老旧软件或系统（如低版本 Office、老旧嵌入式设备）不支持可变字体的动态调整功能，甚至无法识别可变字体文件，此时必须依赖静态字体。
    - **预设样式完整性差异**：少数可变字体可能不会覆盖同家族所有静态字体样式（比如某些小众字体的可变版只包含字重轴，不包含斜体轴），这种情况下就无法完全替代静态斜体字体。

简单来说：**在支持可变字体的现代环境中，安装一个可变字体 ≈ 安装同家族所有静态字体；在不支持的环境中，可变字体可能无法使用**。

## 如何把可变字体嵌入网页
你想知道在 HTML 中嵌入字体时该优先选可变字体还是静态字体，以及具体的嵌入方法，我会结合实用性和兼容性给出清晰的方案。

### 一、字体选择建议
核心原则：**优先用可变字体，同时做好静态字体降级兼容**，具体选择逻辑如下：
| 场景                          | 推荐字体类型       | 原因                                                                 |
|-------------------------------|--------------------|----------------------------------------------------------------------|
| 现代浏览器（Chrome/Firefox/Safari/Edge） | 可变字体（Variable Font） | 单文件体积小、加载快，样式灵活（可微调字重/字宽），减少 HTTP 请求数 |
| 需兼容老旧浏览器（如 IE）| 静态字体（Static Font） | 兼容性无死角，所有浏览器都能识别                                     |
| 通用场景（兼顾体验和兼容）| 可变字体 + 静态字体降级 | 现代浏览器用可变字体，老旧浏览器自动降级到静态字体                   |

### 二、完整嵌入方法（最优方案：可变字体+静态降级）
#### 1. 准备字体文件
- 可变字体文件：如 `SourceHanSans-VF.ttf`（覆盖 100-900 字重）
- 静态字体降级文件：如 `SourceHanSans-Regular.ttf`（400 字重）、`SourceHanSans-Bold.ttf`（700 字重）
- 建议将字体文件放在项目的 `fonts/` 目录下，方便管理。

#### 2. HTML + CSS 嵌入代码（开箱即用）
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>嵌入字体示例</title>
  <style>
    /* 第一步：声明字体（先声明可变字体，再声明静态字体降级） */
    @font-face {
      /* 可变字体声明 */
      font-family: 'SourceHanSans';
      src: url('fonts/SourceHanSans-VF.ttf') format('truetype');
      /* 声明可变字重范围：100-900 */
      font-weight: 100 900;
      font-style: normal;
      /* 字体显示策略：加载时先显示系统字体，加载完成后替换 */
      font-display: swap;
    }

    /* 静态字体降级（针对不支持可变字体的浏览器） */
    @font-face {
      font-family: 'SourceHanSans';
      src: url('fonts/SourceHanSans-Regular.ttf') format('truetype');
      font-weight: 400; /* 固定常规字重 */
      font-style: normal;
      font-display: swap;
    }
    @font-face {
      font-family: 'SourceHanSans';
      src: url('fonts/SourceHanSans-Bold.ttf') format('truetype');
      font-weight: 700; /* 固定粗体字重 */
      font-style: normal;
      font-display: swap;
    }

    /* 第二步：使用字体 */
    body {
      font-family: 'SourceHanSans', sans-serif; /* 最后加系统无衬线字体兜底 */
      font-weight: 450; /* 可变字体：自定义字重（100-900任意值） */
      /* 静态字体降级：浏览器不支持可变字体时，自动匹配最接近的400字重 */
    }
    .bold-text {
      font-weight: 780; /* 可变字体：自定义粗体字重 */
      /* 静态字体降级：匹配700字重 */
    }
  </style>
</head>
<body>
  <p>这是可变字体测试（字重450）</p>
  <p class="bold-text">这是自定义粗体测试（字重780）</p>
</body>
</html>
```

#### 3. 关键代码解释
- `font-display: swap`：避免字体加载时出现“无文字”的闪烁问题，优先显示系统字体，字体加载完成后替换，提升用户体验。
- 字体格式：`format('truetype')` 对应 `.ttf` 文件，若用 `.woff2` 格式（更适合Web，体积更小），需改为 `format('woff2')`，推荐优先用 `woff2` 格式。
- 降级逻辑：当浏览器不支持可变字体时，会自动匹配同 `font-family` 下对应的静态字体字重（如 450 匹配 400，780 匹配 700），最后还会降级到系统 `sans-serif` 字体。

#### 4. 优化建议（提升加载性能）
```bash
# 可选：将TTF字体转换为更优的WOFF2格式（体积更小，加载更快）
# 可使用在线转换工具：https://convertio.co/zh/ttf-woff2/
# 转换后修改src路径和format：
# src: url('fonts/SourceHanSans-VF.woff2') format('woff2');
```

### 三、纯静态字体嵌入（仅兼容老旧浏览器）
如果你的项目只需要兼容老旧浏览器，可直接用静态字体嵌入，示例代码：
```css
@font-face {
  font-family: 'SourceHanSans';
  src: url('fonts/SourceHanSans-Regular.woff2') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: 'SourceHanSans';
  src: url('fonts/SourceHanSans-Bold.woff2') format('woff2');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
}
body {
  font-family: 'SourceHanSans', sans-serif;
  font-weight: 400; /* 只能用预设的400/700等固定字重 */
}
```

### 总结
1. **字体选择**：通用场景优先用「可变字体 + 静态字体降级」，兼顾性能和兼容性；仅兼容老旧浏览器则用纯静态字体。
2. **嵌入核心**：通过 `@font-face` 声明字体，指定 `font-family` 统一名称，设置 `font-display: swap` 优化体验，最后用系统字体兜底。
3. **性能优化**：优先使用 `woff2` 格式字体文件，体积更小、加载更快。
